Completed all changes:

1. **Extracted `internal/ble/` package** — BLE transport separated from device logic:
   - `ble.go`: Protocol, Notification, ScanResult types
   - `client.go`: Client (New, Enable, Scan) with proper scan goroutine cleanup
   - `link.go`: Link (Connect, Write, Notifications, Close, Gen) with generation-tagged notifications

2. **Fixed pairing bug** — Pair/Unpair now write config directly + wake channel:
   - `SetPairedDevice(ctx, addr, name)` — fire-and-forget config write
   - `Pair(ctx, addr, name)` — blocking, polls until connected
   - `Unpair(ctx)` — fire-and-forget config clear + wake
   - Every lifecycle wait/select includes the `wake` channel

3. **Fixed scan interruptibility** — `doScan` now selects on `m.wake` and returns `errConfigChanged`, canceling the scan context and waiting for the goroutine to finish

4. **Fixed scan not finding devices** — `ble.Client.Scan` properly waits for the scan goroutine on stop (1s timeout), buffer increased to 32, no early StopScan

5. **Fixed stale notification bug** — Session generation tracked via `ble.Link.Gen()`, notifications tagged with generation, stale ones discarded in `runSession`

6. **Fixed initial heartbeat session-killer** — Changed from fatal error to `m.logger.Warn("initial battery sync failed", ...)`

7. **Fixed Snapshot pointer aliasing** — `cloneData()` deep-copies `Battery *protocol.BatteryInfo` in both `publishData()` and `Snapshot()`

8. **HTTP handler uses async `SetPairedDevice`** — Returns 202 immediately, client polls status

9. **Clean file structure** — device package: manager.go, requests.go, notify.go, commands.go, state.go (old session/discovery/scan files deleted)
